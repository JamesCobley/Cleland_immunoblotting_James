# Overview
This repository contains the [Python](https://www.python.org/)-scriupted source code described in the methods section of the Cleland immunoblotting [preprint](https://www.biorxiv.org/content/10.1101/2024.09.18.613741v1).
# Source code 
1. The [Cys_PEG-PDB.py](https://github.com/JamesCobley/Cleland_immunoblotting_James/blob/main/Cys_PEG_PDB.py) script attaches maleimide derivatised PEG molecules (2 kDa) to a protein of interest using the PDB file.
2. The [Cys_OX_cal.py](https://github.com/JamesCobley/Cleland_immunoblotting_James/blob/main/Cys_%25oxI_cal.py) script determines the number of possibile k-state solutions to a given protein redox state, such as 10%-oxidised, for a population of molecules in a given R series.
